Klaviaturani qanday yoqaman?

Sozlamalar → Umumiy → Klaviatura → Klaviaturalar → Yangi klaviatura qo‘shish → Alifbo. Keyin yozayotganda 🌐 tugmasini bosib Alifbo’ni tanlang.

«To‘liq ruxsat» kerakmi?

Yo‘q. Klaviatura to‘liq ruxsatsiz ishlaydi va internetga ulanmaydi.

Eski usulda yozsam nima bo‘ladi?

Alifbo Pro bilan «sh, ch, o‘, g‘» deb yozsangiz, klaviatura o‘zi «ş, ç, ö, ğ» qiladi. O‘girish kerak bo‘lmasa, darhol o‘chirish tugmasini bosing.

Boshqa ilovadagi matnni qanday o‘giraman?

Matnni belgilang → «Ulashish» → «Yangi alifboga o‘girish».

Xaridni qanday tiklayman?

Ilovada «Alifbo» bo‘limi → «Xaridlarni tiklash».

Support (English)

Enable the keyboard: Settings → General → Keyboard → Keyboards → Add New Keyboard → Alifbo, then switch with 🌐. Full Access is not needed.

Convert text in other apps: select text → Share → “Convert to New Uzbek”.

Restore purchases: Alifbo tab → Restore Purchases.
